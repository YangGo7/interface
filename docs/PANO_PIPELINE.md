# Panorama Detection Pipeline (Updated)\n\n## Components\n- **Backend**\n  - `backend/app.py`: serves frontend (`/`), temp files (`/temp/<path>`); async detect endpoints `/api/detect`, `/api/detect/status/<job_id>`.\n  - `services/pano_inference.py`: multi-model inference (tooth seg, caries, periapical, CEJ, bonelevel, implant diameter) → overlay PNG + rich metrics.\n  - `services/pano_calc_utils.py`: CEJ/Bonelevel post-processing, PBL computation, mapping detections to teeth.\n  - `services/detect_jobs.py`: threaded job manager for async detect.\n  - Weights: `backend/weights/` (`yolo11_seg_ver1_800_1024px.pt`, `caries_det.pt`, `periapical.pt`, `cej.pt`, `bonelevel.pt`).\n- **Frontend**\n  - `frontend/index.html`, `scripts/index_scripts.js`, `css/index_style.css` (clinical dashboard UI).\n  - Upload + detection, overlay viewer, info panel, simple odontogram grid.\n\n## Model flow (PanoPipeline.run)\n1) **Segmentation** (`pano_seg`): contours only, random colors, inner-rect filter (center must lie inside 90% region) to avoid sinus/spine artifacts.\n2) **Caries** (`caries`) & **Periapical** (`periapical`): boxes/text, inner-rect filter.\n3) **CEJ & Bonelevel** (`cej`, `bonelevel`): CEJ (blue) + Bonelevel (yellow) polylines; PBL per tooth (percent + ratio + level).\n4) **Implant diameter/axis**: `compute_from_gray_with_mask` → diameter line (cyan), axis line (deepsky), text `dia~X.Xmm` (0.5mm bucket); uses `DIAMETER_PIXEL_TO_MM` (env, default 0.1).\n5) **Output**: overlay PNG saved to `temp/detect_*`; metrics passed to status API.\n\n## PBL logic\n- Tooth principal axis vs CEJ/Bonelevel masks → `PBL_ratio = bonelevel_to_root / cej_to_root`; `PBL_percent = ratio * 100`.\n- Level mapping (`pbl_level`): demo rule >85 → 1, 67~85 → 2, else 3.\n- Prosthetic labels (implant/bridge/crown) are excluded from PBL.\n\n## API\n- `POST /api/detect` (form-data: `image`) → `{success, job_id, status_url, case_dir}`.\n- `GET /api/detect/status/<job_id>` →\n  ```json\n  {\n    \"overlay_url\": \"/temp/<case>/pano_overlay_x.png\",\n    \"det_counts\": {\"seg_teeth\", \"caries\", \"periapical\", \"cej_masks\", \"bonelevel_masks\"},\n    \"pbl\": {...}, \"pbl_ratio\": {...}, \"pbl_level\": {...},\n    \"caries_by_tooth\": [[tooth, conf, box], ...],\n    \"periapical_by_tooth\": [[tooth, conf, box], ...],\n    \"caries_by_tooth_best\": {tooth: {conf, box}},\n    \"periapical_by_tooth_best\": {tooth: {conf, box}},\n    \"teeth_present\": [...], \"teeth_missing\": [...],\n    \"diameter_metrics\": [{label, diameter_px, diameter_bucket_px, axis, diameter_line}, ...]\n  }\n  ```\n\n## Rendering rules\n- Inner-rect guard (5% margin) for all detections.\n- Tooth seg: contours only (no fill).\n- CEJ: blue, thin; Bonelevel: yellow, thin. PBL is not drawn on image (only in side panel).\n- Text size small to reduce overlap; implant label is skipped to avoid clash with diameter text.\n\n## Frontend behavior\n- Image upload → `/api/detect` → poll status → display overlay PNG.\n- Info panel shows counts, PBL% + Level, findings.\n- Odontogram grid: `teeth_present/teeth_missing` + caries/periapical best per tooth; color-coded chips (tooth/alert/peri/missing/implant/crown placeholders).\n\n## Config knobs\n- `backend/config.py`: weights, conf/iou/imgsz defaults, CORS, allowed extensions, `DIAMETER_PIXEL_TO_MM` (env override; code default 0.1).\n- Env: `PANO_DEVICE` (cpu/cuda), `DIAMETER_PIXEL_TO_MM` (pixel→mm).\n\n## Notes\n- PBL/Level shown only in side panel; overlay avoids clutter.\n- Implant diameter accuracy depends on correct pixel→mm scaling and original-size coords.\n- Artifacts outside inner region are skipped by design.\n*** End Patch
